# DWIN工程使用说明

## 两个组成部分

1. DGUS界面资源：背景、显示控件和触摸控件，生成到 `DWIN_SET`。
2. T5L OS核程序：Keil C51工程，编译后生成 `DWIN_SET\T5L51.bin`。

工程位于 `firmware/dwin`。DGUS 项目入口是 `DWprj.hmi`；OS 核 Keil 工程入口是 `parcel-terminal-dwin.uvproj`。

## DWIN_SET关键文件

| 文件 | 用途 |
|---|---|
| `00.bmp/01.bmp/02.bmp` | 三个页面的800×480背景源图 |
| `13TouchFile.bin` | 触摸区域、页面切换和动作VP配置 |
| `14ShowFile.bin` | 数值、文本和RTC显示控件配置 |
| `32bg.icl` | 实际供屏幕使用的三页背景图库 |
| `T5L51.bin` | OS核通信程序 |
| `T5LCFG.CFG`、`22_Config.bin` | 屏幕基础配置 |

下载时必须复制完整 `DWIN_SET`，不能只复制BMP；屏幕实际显示背景来自 `32bg.icl`。

## 页面功能

- 页面0：主界面，显示重量、费用、皮重、状态和时间；提供清零、去皮、重新计费和进入设置页。
- 页面1：三张大地区卡片，只有省内、普通省外、偏远地区三个选择和返回按钮，不包含输入框。
- 页面2：通信中断或严重错误提示页。

## 触摸动作

所有业务触摸先写入 `VP 0x1100`：

| 动作码 | 操作 |
|---:|---|
| 1 | 清零 |
| 2 | 去皮 |
| 3 | 重新计费 |
| 4 | 保留，固定三档版不使用 |
| 5 | 标定接口保留 |
| 6/7/8 | 省内/普通省外/偏远地区 |

DWIN OS核读取动作码后形成项目协议帧，动作处理完会把 `0x1100` 清零。

## 重新生成后的注意事项

若使用DGUS软件重新“生成”，可能覆盖已经补丁化的触控与显示文件。应重新运行：

```powershell
.\tools\patch_region_dgus.ps1 -GeneratedPng <最终页面1 PNG> -ProjectRoot <DWIN工程目录>
```

该脚本会重建 `32bg.icl`、恢复三张档位卡片触控范围、删除页面1旧参数控件，并保持状态文本VP修复。
