# 源码阅读索引

## 使用方式

仓库只保留一套可编译源码，避免“正式源码”和“注释副本”发生漂移。阅读、修改和编译均以 `firmware` 目录为准；更完整的逐文件解释见文档 09 和 10。

## STC 源码

| 文件 | 建议先看内容 |
|---|---|
| `firmware/stc/source/main.c` | 总体任务、命令入口、状态帧和 RTC |
| `firmware/stc/source/weight_service.c` | 零点、皮重、换算和稳定窗口 |
| `firmware/stc/source/billing.c` | 三档参数与向上取整公式 |
| `firmware/stc/source/parcel_protocol.c` | CRC、定长帧与大端整数 |
| `firmware/stc/inc/project_config.h` | 实际运行开关和周期参数 |
| `firmware/stc/inc/*.h` | 数据结构、动作码和模块接口 |

## DWIN 源码

| 文件 | 建议先看内容 |
|---|---|
| `firmware/dwin/user/main.c` | OS 核初始化和软定时器调用关系 |
| `firmware/dwin/user/parcel_link.c` | 收发帧、VP 更新、触摸、ACK 和重试 |
| `firmware/dwin/user/page.c` | 页面进入/循环/离开回调机制 |
| `firmware/dwin/user/deal.c` | 官方底座遗留的文本位置演示代码，非核心业务 |
| `firmware/dwin/user/key_scan.c` | 通用键值扫描示例，当前项目触摸不依赖它 |

## 厂家/课程库说明

STC 芯片寄存器头文件、STCBSP 库、UART/EXT/DS1302/M24C02 课程驱动、DWIN 的 `sys/driver` 目录和通用 DGUS 工具属于课程或厂家底座。项目只通过接口调用它们，阅读时重点关注调用参数与返回值。

## 同步规则

功能修改应直接提交到 `firmware` 中的唯一源码，并同步更新相关编号文档。提交前至少运行计费边界测试，并在条件允许时完成两端编译与实物联调。
