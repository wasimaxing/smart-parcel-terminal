# 协议、VP与计费规则

## RS-485定长帧

```text
AA 55 | DST | SRC | CMD | SEQ | LEN | DATA[18] | CRC8
```

总长度26字节。CRC使用CRC-8/ATM，多项式 `0x07`、初值 `0x00`，覆盖DST到完整18字节DATA。多字节整数统一大端序。

## 主要命令

| 命令 | 方向 | 用途 |
|---:|---|---|
| `0x01` | STC→DWIN | 重量、费用、状态、皮重快照 |
| `0x02` | STC→DWIN | 当前固定计费参数和地区 |
| `0x03` | STC→DWIN | DS1302时间 |
| `0x10` | DWIN→STC | 清零 |
| `0x11` | DWIN→STC | 去皮 |
| `0x12` | DWIN→STC | 重新计费 |
| `0x13` | 保留 | 固定三档版拒绝自定义价格 |
| `0x15` | DWIN→STC | 切换地区1/2/3 |
| `0x7E/0x7F` | 回复 | ACK/NACK |

## 主要VP

| VP | 类型 | 用途 |
|---:|---|---|
| `0x1000～0x1001` | S32 | 重量，单位g |
| `0x1002～0x1003` | U32 | 费用，单位分 |
| `0x1005` | U16 | 稳定、传感器、量程和参数标志 |
| `0x1006～0x100D` | 4×U32 | 当前首重/续重参数，供主页规则显示 |
| `0x100F` | U16 | 错误码 |
| `0x1010～0x1011` | S32 | 皮重，单位g |
| `0x1030` | U16 | 地区编号 |
| `0x1031` | U16 | 系统状态编号 |
| `0x1100` | U16 | 触摸动作码 |
| `0x1102` | U16 | 动作诊断回显 |
| `0x1103` | U16 | 命令等待/成功/失败状态 |
| `0x1220` | ASCII 10字节 | 状态短文本 |
| `0x1230` | ASCII 20字节 | 状态说明 |
| `0x0010～0x0013` | 系统RTC区 | 年月日星期时分秒 |

32位数值连续占两个VP。屏幕显示小数点只负责格式化，不改变VP中的克或分。

## 计费公式

```text
重量 <= 0：费用=0
0 < 重量 <= 首重：费用=首重价
重量 > 首重：费用=首重价 + ceil((重量-首重)/续重单位) × 续重价
```

示例：省内2001 g，超出首重1001 g，需要2个续重单位，费用为8+2×2=12元。
