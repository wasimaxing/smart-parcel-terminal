# DGUS 页面制作表

屏幕型号按现有资料暂定 EKT043_EDU，使用 90° 横屏，画布 800×480。BMP 文件已去除动态数值；`dwin_assets/preview` 中的 PNG 仅用于查看完成效果。

## 页面 0 - 主页面 `00_main.bmp`

| 控件 | VP | 建议区域（x, y, w, h） | 格式 |
|---|---:|---|---|
| 净重数值 | 0x1000 | 48,132,300,82 | 5 位整数，3 位小数，单位 kg |
| 稳定状态 | 0x1005 | 330,96,120,24 | 图标/文本状态 |
| 皮重 | 0x1010 | 244,254,70,20 | 0 位小数，单位 g |
| 应付金额 | 0x1002 | 558,130,190,64 | 2 位小数，单位元 |
| 首重规则 | 0x1006 + 0x1008 | 560,214,170,24 | 两个数值控件组合显示 |
| 续重规则 | 0x100A + 0x100C | 560,244,170,24 | 两个数值控件组合显示 |
| 状态文本 | 0x1220 | 42,323,120,30 | ASCII 文本，长度 10 |
| 状态说明 | 0x1230 | 176,324,360,28 | ASCII 文本，长度 20 |
| RTC时间 | 系统RTC区0x0010～0x0013 | 666,328,90,20 | RTC显示控件，格式 `H:Q:S` |

触摸区域：

| 操作 | 写入 VP | 按键区域 |
|---|---:|---|
| 清零 | 0x1100 写 1 | 22,394,181,62 |

## 页面 1 - 参数设置 `01_rate_settings.bmp`

设置页不放置参数文本框、数据变量显示控件或“变量数据录入”控件，也不发送 `action_code=4`。页面使用三张大档位卡片填充中部区域，分别显示档位名称、首重价和续重价；三张卡片写入 `action_code=6/7/8`，由 STC 切换固定价目表。底部“返回主界面”按钮直接切换回页面 0。

| 档位卡片 | 动作码 | 触控区域（x1,y1,x2,y2） |
|---|---:|---|
| 省内 | 6 | 32,112,262,352 |
| 普通省外 | 7 | 285,112,512,352 |
| 偏远地区 | 8 | 535,112,764,352 |

## 页面 2 - 异常页 `02_error.bmp`

当前页面以“通信中断”为样例。正式工程建议用同一背景加文本/图标变量显示：

- 传感器无响应；
- 重量超量程；
- 标定数据无效；
- 板间通信中断。

“重新检测”按钮不直接清除错误，只发送心跳/刷新请求；主控确认异常解除后再返回主页面。

## 导入与检查

1. 新建 800×480、90° 方向的 DGUS 工程；
2. 按页面号导入三个 BMP；
3. 依据本表叠加数值、文本和触摸控件；
4. 与 `variable-map.md` 逐项核对 VP，禁止在屏幕工程里另建一套地址；
5. 用 DGUS 模拟器检查边界值：0、1.000、1.001、30.000、30.001 kg；
6. 下载到屏幕后再检查触摸区域，不以 PC 模拟器代替实物验收。
