# MVP 核心测试用例

默认参数：首重 1000 g / 800 分；续重单位 1000 g / 400 分；最大量程 30000 g。

## 计费边界

| 编号 | 输入重量 | 预期金额 | 目的 |
|---|---:|---:|---|
| B01 | 0 g | 0 分 | 空载不计费 |
| B02 | 1 g | 800 分 | 最小正重量进入首重 |
| B03 | 1000 g | 800 分 | 首重上边界 |
| B04 | 1001 g | 1200 分 | 续重向上取整 |
| B05 | 2000 g | 1200 分 | 第一续重边界 |
| B06 | 2001 g | 1600 分 | 第二续重开始 |
| B07 | 30000 g | 12400 分 | 最大量程内 |
| B08 | 30001 g | 不计费并报超量程 | 最大量程外 |

## 称重与状态

| 编号 | 操作 | 预期 |
|---|---|---|
| W01 | 空秤上电 | 完成零点采样，状态 IDLE |
| W02 | 连续改变负载 | 状态 WEIGHING，不更新应付金额 |
| W03 | 连续样本进入稳定阈值 | 状态 STABLE/BILLING，金额更新一次 |
| W04 | 有容器时执行去皮 | 净重归零，皮重被记录 |
| W05 | 传感器无响应/原始值越界 | 状态 ERROR，显示传感器异常 |
| W06 | 10 次放置同一砝码 | 记录最大误差、平均值和极差 |

## 通信与交互

| 编号 | 操作 | 预期 |
|---|---|---|
| C01 | 连续接收有效心跳 | 显示“通信正常” |
| C02 | 超过设定时间未收到心跳 | 状态 ERROR，显示通信中断 |
| C03 | 校验和错误 | 丢弃整帧，不更新界面 |
| C04 | 连续点击一次清零 | action_seq 只触发一次有效清零 |
| C05 | 写入非法计费参数 | 主控拒绝保存并返回错误码 |
| C06 | 通信恢复 | 自动清除通信错误并刷新完整状态 |

## 通过门槛

- 所有 B 类用例结果完全一致；
- W06 的误差满足课程或传感器允许范围，并保留原始记录；
- RS-485 连续运行 30 分钟无死机、无持续丢帧；
- 断线、超量程、传感器异常均可在 2 秒内给出明确提示；
- 清零、去皮和重新计费各连续操作 20 次无状态错乱。
