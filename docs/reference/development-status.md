## 当前固件行为

STC 的 `LINK_TEST_MODE` 已切换为 0。上板后每 500 ms 发送 EXT 电子秤的实测状态；由于 BSP 的 `GetWeight()` 返回未清零、未标定的 16 位有符号 ADC 原始值，首次使用必须完成零点和已知砝码标定。

实秤联调按以下顺序执行：

1. 空秤清零；
2. 放置已知砝码，在 `0x1118` 写入克数并触发动作码 5；
3. 检查多个重量点；
4. 检查多个重量点以及去皮、重新计费功能。
