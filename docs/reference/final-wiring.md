# 最终接线表（MVP）

更新日期：2026-09-03

## 冻结拓扑

```text
电子秤 ── EXT ── STC 主控板 ── 板载 RS-485 ── EKT043_EDU
```

第二块相同 STC 学习板暂不接入主流程，保留给后续测高、RFID 或故障替换。

## 1. 电子秤接 STC 的 EXT

| STC EXT 引脚 | 原理图网络 | 本项目用途 |
|---|---|---|
| 1 | VUSB / 5V | 秤模块电源；仅在确认模块允许 5V 后连接 |
| 2 | P1.1 | 称重时钟 SCK（依据 BSP 的 HX710/HX711 接口方向推定） |
| 3 | P1.0 | 称重数据 DOUT（依据 BSP 的 HX710/HX711 接口方向推定） |
| 4 | GND | 秤模块地 |

电子秤没有明显丝印，所以不能按线色直接接电。先用万用表找出 GND 与供电线，或补拍插头和模块正反面，再确认四根线顺序。

程序初始化必须保留称重模式：

```c
EXTInit(enumEXTWeight);
Uart2Init(9600UL, Uart2Usedfor485);
MySTC_Init();
```

- 不要使用 `Uart2UsedforEXT`，否则 EXT 会变成 TTL 串口，称重失效；
- `EXTInit(enumEXTWeight)` 使用 P1.0/P1.1 采集称重；
- `Uart2Usedfor485` 把 UART2 映射到 P4.6/P4.7，并使用板载 MAX485；
- 课程 BSP 是预编译库，首次上板要验证两个初始化能否同时保持有效。验证标准是：反复调用 `GetWeight()` 时，板载 485 仍能连续发送测试帧。
- 按课程示例，外设初始化和回调注册放在 `MySTC_Init()` 之前。

## 2. STC 板载 RS-485 接 DWIN

务必断电接线。

| STC 学习板 | EKT043_EDU | 说明 |
|---|---|---|
| CON2-2：A | 39：UART4/485A | 485 A 线 |
| CON2-1：B | 40：UART4/485B | 485 B 线 |
| GND | 55～58 中任一 GND | 两端共地 |

若通信无数据，先检查波特率和共地；只有在确认两端标注规则相反时才交换 A/B，不要带电换线。

## 3. 供电

- EKT043_EDU：使用独立 12V/1A 稳压电源；
- STC 学习板：使用其规定的 5V/USB 供电；
- 两路电源只共地，不把 DWIN 的 12V 接到 STC 或 EXT；
- 第一次通电先不接电子秤，只验证 STC 固定测试帧能到 DWIN；通信通过后再断电接入电子秤。

## 4. DWIN 串口设置

- 接口：UART4/RS-485；
- 波特率：9600；
- 数据格式：8N1；
- 需要启用 UART4 与 UART4 的 485 方向控制；
- T5L OS 接收项目自定义固定帧，再把值写到 DGUS VP 地址。

## 5. 首次联调顺序

1. STC 与 DWIN 断电接好 A、B、GND；电子秤暂不连接；
2. STC 每 500 ms 发送固定重量和价格，确认 DWIN 页面更新；
3. 断电后接电子秤，空秤读取 `GetWeight()` 原始值并观察稳定性；
4. 执行零点采集，再放已知砝码求标定系数；
5. 最后启用滤波、稳定判断和计费，禁止把未标定的原始 ADC 值直接当克数。
