# 编译、烧录与联调排错

## 推荐更新顺序

1. 先备份当前可运行版本。
2. 编译STC工程，确认0错误并生成新的HEX。
3. 编译DWIN OS核，确认0错误并生成 `T5L51.bin`。
4. 确认DGUS资源已经生成/补丁处理，`DWIN_SET`文件齐全。
5. 使用STC-ISP烧录STC HEX。
6. 将完整 `DWIN_SET`复制到FAT32卡根目录，屏幕断电插卡后上电更新。
7. 断电、移除存储卡、连接RS-485后重新上电验收。

## 最小验收

- 主界面不再停留在通信中断页。
- 重量随电子秤变化，K1和屏幕清零都有效。
- 省内/普通省外/偏远地区卡片均能切换费用。
- 0、1、1000、1001、2000、2001 g边界费用正确。
- 断电后保留最后选择的地区。
- RTC问题不影响称重和计费主功能。

## 常见问题

### TX灯闪但屏幕数据不变

检查A/B是否接反、两板是否共地、两端波特率是否均为9600、DWIN使用UART4而STC使用UART2，并确认烧录的是同一版本协议。

### 屏幕始终显示0

先读取诊断VP `0x1102～0x1104`，再确认STC发送的是项目26字节帧而不是DGUS的 `5A A5`调试读写帧。`5A A5`是屏幕调试协议，不是两板间业务协议。

### 清零按钮无效但K1有效

称重模块通常正常，重点检查触摸是否写入 `0x1100=1`、DWIN UART4是否发帧、STC RX灯是否闪烁，以及ACK状态 `0x1103`。

### 地区卡片点击无效

动作码应为6/7/8，触控区域必须在页面1；STC收到后会回ACK和新的参数帧。动作码4是保留值，不应出现。

### DGUS软件重新生成后界面退回旧版

重新运行 `tools\patch_region_dgus.ps1`，然后再次复制完整 `DWIN_SET`。只替换BMP不会改变屏幕实际的ICL背景和触控配置。
