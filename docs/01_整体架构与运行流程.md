# 整体架构与运行流程

## 系统组成

- STC15F2K60S2主控板：采集电子秤、完成清零/去皮/稳定判断、计算费用、保存地区编号并读取DS1302。
- 电子秤/HX711板：通过STC的EXT称重接口提供原始重量数据。
- DWIN T5L屏：负责页面显示、触摸输入、命令重发和通信超时提示。
- RS-485：STC UART2与DWIN UART4之间的半双工链路，参数为9600 bps、8N1。
- M24C02：只保存当前地区编号；费率固定在STC程序代码中。

## 数据流

```text
HX711/电子秤
     │ EXT原始值
     ▼
STC称重服务 ──► 稳定判断 ──► 三档计费 ──► STATUS/PARAMS帧
     ▲                                            │
     │ 清零、去皮、地区命令                        │ RS-485
     │                                            ▼
     └────────────────────────────────────── DWIN屏
                                      VP更新、页面显示、触摸
```

## 正常运行顺序

1. STC启动，读取M24C02中保存的地区；无效时选择省内。
2. STC读取电子秤原始值，进行零点、去皮、平均滤波和稳定判断。
3. 重量稳定且参数有效时，按当前地区计算费用。
4. STC每500 ms发送状态帧，地区变化时发送参数帧。
5. DWIN收到帧后更新重量、费用、状态和地区显示。
6. 用户点击清零、去皮或地区卡片，DWIN形成命令帧并等待STC的ACK。
7. 120 ms未收到ACK时DWIN重发，最多3次；STC通过命令号和序号去重。
8. DWIN连续2秒未收到状态帧时进入通信中断页。

## RTC现状

当前程序以STC板的DS1302为时间源，每秒发送一次RTC帧，DWIN写入系统RTC区显示。已知该批次DS1302可能存在写入异常，因此RTC仅用于界面展示，不参与称重或计费；若硬件测试仍不可靠，可继续改成上电软件计时或确认屏幕背板是否装有RX8130/SD2058。
