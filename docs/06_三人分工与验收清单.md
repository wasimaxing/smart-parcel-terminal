# 三人分工与验收清单

## 成员A：STC与电子秤

- 负责EXT/HX711读取、清零、去皮、滤波和稳定判定。
- 维护 `main.c`、`weight_service.c` 和硬件接线。
- 验证K1清零、屏幕清零、负重变化和30 kg量程。

## 成员B：DWIN界面

- 负责三个页面、VP、三档卡片触控和DWIN_SET生成。
- 维护 `parcel_link.c`、DGUS控件和页面背景。
- 验证页面跳转、状态文本、异常页、三档触控和存储卡下载。

## 成员C：协议、计费与集成

- 负责RS-485帧、CRC、ACK/重试、计费公式和集成测试。
- 维护 `parcel_protocol.c`、`billing.c`、协议文档和测试用例。
- 验证边界费用、重复帧去重、通信中断/恢复和版本打包。

## 共同答辩要点

- 为什么使用克和分而不使用浮点数。
- 为什么续重要向上取整。
- VP是屏幕变量地址，触控先写VP，再由OS核发命令。
- STC UART2与称重EXT可以并行使用，前提是硬件引脚映射不冲突。
- ACK重试解决丢帧，STC去重避免重发导致重复去皮。
- 三档费率固定在STC，屏幕只选择地区，因此规则不能被误输入修改。
